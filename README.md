# Diana Torres — Editorial Portfolio

A responsive, single-page portfolio inspired by an editorial, photo-led approach. White background, fine Peruvian-inspired line borders, and space for personal photographs.

## Preview
Open `index.html` in a browser. The hero initially shows a neutral background; photo sections show elegant placeholders.

## Add photographs
Put your images in the `images` folder with these **exact filenames**:

- `hero.jpg` — large, wide professional photo for the cover (recommended 2000 × 1200 pixels or larger)
- `roots.jpg`, `public-service.jpg`, `ipa.jpg`, `berkeley.jpg` — About Me chapters
- `project-ipa.jpg`, `project-government.jpg`, `project-waterscope.jpg` — projects
- `moment-1.jpg`, `moment-2.jpg`, `moment-3.jpg` — gallery

Photos can be added gradually. For each About/project/gallery image, the placeholder automatically disappears when its photo loads.

## Publish with GitHub Pages
1. Create a GitHub repository or open the existing portfolio repository.
2. Upload **the contents** of this folder (not the folder itself) to the repository root.
3. In GitHub, go to Settings → Pages → Build and deployment → Deploy from a branch → main / root → Save.
4. Allow a few minutes for the site to deploy.

## Customize
Edit `index.html` for copy, sections, layout, colors and image filenames. Edit `textile-border.svg` for the decorative lines.
